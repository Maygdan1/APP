#  🎂 Birthday Telegram WebApp & Bot

Telegram Mini App и бот для автоматических поздравлений.

## 🚀 Основные возможности

- Заполнение и обновление даты рождения через Telegram Mini App.
- Календарь дней рождения для утвержденной учебной группы.
- Годовой обзор календаря, начиная с текущего месяца.
- Роли: администратор, наставник и студент.
- Управление учебными группами и их статусом.
- Фильтрация групп в панели управления.
- Экспорт данных доступных групп в CSV.
- Автоматическая отправка поздравлений в активные чаты или топики.
- Одноразовая заявка на подключение группы по секретному ключу.
- Ручное включение, отключение и редактирование групп.
- Переключатели для временной остановки заявок и регистрации новых пользователей.

## 🛠 Технологический стек

* **Backend:** Node.js, Express, Grammy (Telegram Bot API Framework), Mongoose (MongoDB)
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Telegram WebApp SDK

## Роли

### Студент

Студент заполняет форму и может обновлять свои данные. После подтверждения группы ему доступен календарь только этой группы. Календарь показывает полный годовой период, начиная с текущего месяца, без фильтров.

### Наставник

Наставник видит свой профиль, прикрепленные группы, календарь своих групп и может выгружать данные по всем или отдельным доступным группам.

### Администратор

Администратор видит всех пользователей, назначает роли и группы, управляет подключениями, проверяет доступность бота, меняет настройки защиты и создает резервные копии.

## ⚙️ Переменные окружения (.env)

Создайте локальный `.env` и задайте значения переменных окружения:

```env
BOT_TOKEN=...
MONGO_URI=...
SESSION_SECRET=случайная_строка
PORT=10000
```

Секреты не должны попадать в Git, README, скриншоты или публичные сообщения.

## Подключение группы

Порядок подключения:

1. Добавьте бота в нужную Telegram-группу.
2. Назначьте его администратором с правом отправки сообщений. Если подключается отдельный топик, дополнительно выдайте боту право управления темами.
3. Сообщите администратору системы, что все пункты выполнены. Укажите название группы в Telegram и её реальное название, например: `БИВТ-26-6-1`.
4. Дождитесь сообщения-ключа от администратора и скопируйте его.
5. Отправьте ключ в группу или нужный топик без изменений:

```text
@имя_бота(сгенерированный-токен)
```

6. Сообщите администратору системы, что ключ отправлен. Он проверит подключение и включит группу для рассылки поздравлений.

Обычные сообщения в группах бот игнорирует. Он реагирует только на сообщение с упоминанием своего `@username` и корректным токеном приглашения. Токен одноразовый: после использования он становится недействительным. Не пересылайте приглашение посторонним.
